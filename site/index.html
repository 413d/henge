Capabilities

Built to stay out of your way

Deterministic layout conversion modeled after macOS native keymaps — no AI guessing, no background interference.

Selection or word at cursor

Converts your active selection first. When nothing is selected, Henge detects the word around or immediately before your caret.

Detects direction from text

Majority-letter detection inspects the typed characters themselves, so RU ↔ EN conversion works regardless of your current macOS input source.

Preserves case, digits, and _

Keeps uppercase, lowercase, title case, digits, underscores, and trailing delimiter punctuation intact — ideal for both chat and code.

Quiet menu bar utility

Runs with no Dock icon. Remap the shortcut, exclude terminals or IDEs, and toggle Launch at Login in Settings.

Privacy & Safety

Zero network calls. Zero password access.

Every safety invariant is enforced in the open-source Swift codebase before a single character is read or replaced.

100% offline & local

Henge makes zero network requests, collects no telemetry, and stores preferences locally at ~/Library/Application Support/Henge/config.json.

Password field immunity

Secure text fields (AXSecureTextField) are blocked at every layer — Henge never reads, copies, transforms, or logs their content.

Accessibility first, clipboard restored

Reads and replaces text via macOS Accessibility APIs first. When an app requires clipboard fallback, Henge snapshots and immediately restores your pasteboard.

Honest boundaries

  • RU ↔ EN only: Henge converts exclusively between Russian and English keyboard layouts.
  • Manual trigger only: text changes only when you press ⌥X (or click Fix Text), never silently in the background.
  • Ad-hoc signed builds: after updating Henge.app to a new version, macOS asks you to re-enable Accessibility access.

Installation

Up and running in seconds

Requires macOS 13 Ventura or later. One Universal build supports both Apple Silicon and Intel Macs.

Homebrew (no Gatekeeper prompt)

Recommended

Verifies SHA-256, installs Henge.app, and clears the macOS quarantine attribute automatically:

brew tap 413d/henge https://github.com/413d/henge && brew install --cask 413d/henge/henge

One-command installer

No Homebrew needed

Verifies SHA256SUMS.txt before extraction, checks codesign, clears quarantine, and installs to /Applications or ~/Applications:

curl -fsSL https://raw.githubusercontent.com/413d/henge/main/scripts/install.sh | bash

Or install manually from the GitHub Release .zip archive:

  1. 1

    Download and move to Applications

    Download Henge-v*-universal.zip from the latest GitHub Release, extract Henge.app, and move it to /Applications or ~/Applications.

  2. 2

    Allow first launch in macOS Gatekeeper

    Public releases are ad-hoc signed without a paid Apple Developer ID. Choose either way to approve Henge.app on first launch:

    Option 2A — GUI (Apple's official instruction, no Terminal needed)

    Try opening Henge.app once and click Done on the unverified-app prompt. Then open System Settings → Privacy & Security, scroll to Security, click Open Anyway next to Henge, and confirm.

    Option 2B — Terminal (one command)

    xattr -dr com.apple.quarantine ~/Applications/Henge.app

    Why this is needed: macOS 15 Sequoia asks for confirmation on unnotarized browser downloads. You can also verify SHA-256 via shasum -a 256 -c SHA256SUMS.txt or build from source.

    Verify SHA-256 checksums
  3. 3

    Launch & grant Accessibility

    Open Henge.app and enable it under System Settings → Privacy & Security → Accessibility so it can fix text in other apps.

FAQ

Common questions

Clear answers on how Henge differs from automatic layout switchers, password safety, and Gatekeeper setup.

How is Henge different from automatic switchers like Punto Switcher?

Henge only transforms text when you press ⌥X. It never monitors keystrokes in the background, never auto-switches mid-sentence while coding or messaging, and is 100% open-source (MIT) and offline.

Is Henge safe for passwords and completely offline?

Yes. Henge makes zero network requests, logs no user text or clipboard contents, and strictly skips password and secure input fields (AXSecureTextField).

Does Henge work on Apple Silicon and Intel Macs?

Yes. Every release ships as a Universal macOS binary supporting both Apple Silicon (M1–M4) and Intel Macs on macOS 13 Ventura and later.

How do I open Henge.app on first launch if macOS Gatekeeper shows a warning?

Public GitHub releases are ad-hoc signed without a paid Apple Developer ID certificate. If you install via Homebrew (brew tap 413d/henge https://github.com/413d/henge && brew install --cask 413d/henge/henge) or the curl installer script, quarantine is cleared automatically. For manual .zip downloads, either follow Apple's official GUI flow (try opening Henge.app once, then go to System Settings → Privacy & Security → Open Anyway) or run xattr -dr com.apple.quarantine ~/Applications/Henge.app once in Terminal.

Which languages and shortcuts does Henge support?

Henge focuses exclusively on bidirectional Russian ↔ English (RU ↔ EN) keyboard layout conversion. The default shortcut is ⌥X and can be customized in Settings.
