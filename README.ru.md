<h1>Henge</h1>

**Исправление текста, набранного не в той раскладке, одним сочетанием клавиш.**

Лёгкая утилита для строки меню macOS с упором на приватность: превращает `ghbdtn` в `привет` (а `руддщ` в `hello`) по нажатию одной горячей клавиши.

## Зачем нужен Henge

Каждый, кто переключается между русской и английской клавиатурами, знает это чувство: вы печатаете целое слово или предложение, смотрите на экран и видите `ghbdtn` вместо `привет` — или `руддщ` вместо `hello`.

Вместо того чтобы всё стирать и набирать заново, нажмите **`⌥X`**. Henge преобразует выделенный текст или слово под курсором без необходимости предварительно переключать раскладку.

## Возможности

| Возможность | Как это помогает |
| --- | --- |
| **Выделение или слово под курсором** | Исправляет текущее выделение или автоматически берёт слово вокруг курсора, если ничего не выделено |
| **Автоопределение RU ↔ EN** | Определяет направление раскладки по самим набранным символам, а не по активному источнику ввода macOS |
| **Сохранение форматирования** | Сохраняет заглавные и строчные буквы, цифры, знаки препинания и символ `_` |
| **Утилита в строке меню** | Тихо работает в строке меню macOS, не занимая место в Dock |
| **Настраиваемое сочетание клавиш** | По умолчанию `⌥X`; можно переназначить на любое сочетание с модификаторами в **Настройки → Основные** (**Settings → General**) |
| **Исключения для приложений** | Исключайте терминалы, IDE или определённые приложения в **Настройки → Исключения** (**Settings → Exceptions**) |
| **Запуск при входе** | Может запускаться автоматически при входе в систему (**Настройки → Основные**) |

## Установка

**Требуется macOS 13 Ventura или новее.** Единый универсальный архив поддерживает как компьютеры Apple Silicon (M1 и новее), так и Mac на базе процессоров Intel.

### Способ 1 — Homebrew (Рекомендуется, без предупреждений карантина)

```bash
brew tap 413d/henge https://github.com/413d/henge
brew install --cask 413d/henge/henge
```

Homebrew проверяет контрольную сумму SHA-256 релиза, устанавливает `Henge.app` и автоматически снимает атрибут `com.apple.quarantine` на этапе `postflight_steps`.

### Способ 2 — Установка одной командой (Homebrew не требуется)

```bash
curl -fsSL https://raw.githubusercontent.com/413d/henge/main/scripts/install.sh | bash
```

Скрипт проверяет контрольную сумму из `SHA256SUMS.txt` на GitHub Releases **до** распаковки, проверяет подпись `codesign` и идентификатор пакета, очищает `com.apple.quarantine` и устанавливает приложение в `/Applications` (или в `~/Applications`, если каталог `/Applications` недоступен для записи — пароль `sudo` не требуется).

### Способ 3 — Ручная загрузка `.zip`

1. Скачайте **`Henge-vX.Y.Z-universal.zip`** из последнего [релиза на GitHub](https://github.com/413d/henge/releases/latest)
   *(выбирайте файл `Henge-v*.zip` — архивы `Source code`, создаваемые GitHub автоматически, содержат только исходный код; внутри архива с приложением также находится `INSTALL.txt`).*
2. Дважды нажмите на zip-архив, чтобы извлечь **`Henge.app`**, затем переместите его в **`/Applications`** или **`~/Applications`**.
3. **Разрешите первый запуск в macOS Gatekeeper** *(публичные сборки подписаны ad-hoc подписью без платного сертификата Apple Developer ID)* — выберите **любой** из двух способов:
   - **Через интерфейс (официальный способ Apple — Терминал не требуется):** дважды нажмите на `Henge.app` и нажмите **Готово** (или **OK**) в окне с предупреждением о непроверенном приложении. Затем откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите до раздела **Безопасность**, нажмите **Подтвердить вход** (или **Всё равно открыть**) рядом с Henge и подтвердите запуск.
   - **Через Терминал:** снимите атрибут карантина перед запуском:

     ```bash
     xattr -dr com.apple.quarantine ~/Applications/Henge.app
     ```

     *(Если приложение установлено для всех пользователей в `/Applications`, укажите `/Applications/Henge.app`.)*
4. Запустите **`Henge.app`** и предоставьте разрешение **Универсальный доступ** (Accessibility) при появлении запроса (или перейдите в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**).

### Почему Gatekeeper выдаёт предупреждение при ручной загрузке `.zip`

Сборки Henge с открытым исходным кодом прозрачно собираются в GitHub Actions с **ad-hoc подписью** и не нотаризуются платным сертификатом Apple Developer ID. Файлы, скачанные через браузер, получают атрибут `com.apple.quarantine`, из-за чего macOS (особенно macOS 15 Sequoia) требует явного подтверждения первого запуска через **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** или с помощью команды `xattr -dr com.apple.quarantine`. При установке через Homebrew или скрипт `install.sh` контрольная сумма проверяется, а карантин снимается автоматически; также вы можете [собрать приложение из исходников](#сборка-из-исходников) прямо на своём Mac.

### Проверка скачанного файла

Скачайте `SHA256SUMS.txt` из того же релиза в папку с zip-архивом и выполните:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Это проверит целостность архива по результатам сборки в CI.

## Как пользоваться

1. Наберите текст не в той раскладке клавиатуры (например, `ghbdtn` или `Ghbdtn, vbh!`).
2. Либо **выделите текст**, либо оставьте **курсор внутри слова или в его конце**.
3. Нажмите **`⌥X`** (Option + X).

Henge заменит текст на месте. Вы также можете нажать на иконку в строке меню, чтобы:

- Включить или выключить Henge (**Enabled / Disabled**)
- Вызвать **Исправить текст** (**Fix Text**) вручную
- Проверить разрешения **Универсального доступа** (Accessibility) и статус регистрации горячей клавиши
- Открыть **Настройки…** (**Settings…**), чтобы изменить сочетание клавиш, настроить **Исключения** (**Exceptions**) или переключить **Запуск при входе** (**Launch at Login**)

## Приватность и безопасность

- **100% офлайн.** Henge не выполняет сетевых запросов, не отправляет телеметрию или аналитику и не требует создания аккаунта.
- **Защита полей паролей и защищённого ввода.** Henge проверяет тип текстового поля и гарантированно не читает, не копирует, не трансформирует и не заменяет содержимое защищённых полей.
- **Приоритет Accessibility, восстановление буфера обмена.** Henge читает и записывает текст напрямую через API универсального доступа (macOS Accessibility). Для приложений, не поддерживающих прямую замену через Accessibility, Henge использует резервный механизм копирования/вставки и сразу же восстанавливает предыдущее содержимое вашего буфера обмена.
- **Локальная конфигурация.** Настройки хранятся локально по пути `~/Library/Application Support/Henge/config.json`.

## Честные ограничения

- **Только RU ↔ EN.** Поддерживается преобразование только между русской и английской раскладками клавиатуры.
- **Без фонового автоисправления.** Henge преобразует текст только тогда, когда вы нажимаете горячую клавишу (или выбираете **Fix Text** в меню).
- **Ad-hoc подпись и разрешения.** Поскольку релизные сборки подписаны ad-hoc подписью без платного сертификата Developer ID, macOS сбрасывает выданное разрешение на Универсальный доступ при замене `Henge.app` на новую версию — повторно включите Henge в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** после обновления.
- **Различия в совместимости приложений.** Некоторые нестандартные UI-фреймворки, изолированные приложения (sandbox) или окна удалённого рабочего стола ограничивают доступ к Accessibility; в таких случаях Henge безопасно прекращает операцию (no-op), если целевое поле нельзя безопасно прочитать или отредактировать.

## Обновление и удаление

**Обновление:**
- **Homebrew:** `brew upgrade --cask 413d/henge/henge`
- **Скрипт установки:** запустите повторно `curl -fsSL https://raw.githubusercontent.com/413d/henge/main/scripts/install.sh | bash`
- **Вручную через `.zip`:** выберите **Quit Henge** в строке меню, замените `Henge.app` в `/Applications` или `~/Applications`, разрешите первый запуск через **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** или `xattr -dr com.apple.quarantine` и при необходимости заново включите **Универсальный доступ**.

**Удаление:**

1. Отключите **Запуск при входе** (**Launch at Login**) в **Настройки → Основные**, затем нажмите **Quit Henge**.
2. Удалите Henge (`brew uninstall --cask 413d/henge/henge`, если приложение устанавливалось через Homebrew) и удалите папку локальной конфигурации:

   ```bash
   rm -rf /Applications/Henge.app ~/Applications/Henge.app "$HOME/Library/Application Support/Henge"
   ```

## Сборка из исходников

Требуются macOS 13+ и инструменты командной строки Swift / Xcode (`xcode-select --install`).

```bash
git clone https://github.com/413d/henge.git
cd henge
./scripts/build.sh --install
open ~/Applications/Henge.app
```

Полезные команды для контрибьюторов:

```bash
swift test                        # запуск набора модульных тестов
./scripts/build.sh universal      # сборка универсального бандла arm64 + x86_64
./scripts/package.sh              # упаковка dist/Henge-universal.zip + SHA256SUMS.txt
swift run Henge --probe help      # проверка нативных зондов API (layout, ax, clipboard, hotkey)
```

Чтобы сохранить разрешения Универсального доступа macOS между локальными пересборками, подпишите приложение локальным сертификатом из Связки ключей (Keychain):

```bash
HENGE_SIGNING_IDENTITY="Henge Local" ./scripts/build.sh --install
```

Мейнтейнеры могут опубликовать новый тегированный релиз на GitHub Releases (для стабильных тегов воркфлоу `Release` автоматически обновляет `Casks/henge.rb` в `main` после загрузки `SHA256SUMS.txt`):

```bash
git tag v0.2.0
git push origin v0.2.0
# Ручной резервный запуск при необходимости:
./scripts/release/update-cask.sh --no-downgrade 0.2.0 <sha256>
```
